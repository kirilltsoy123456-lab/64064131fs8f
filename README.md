# Telegram-бот учета посещаемости

Бот напоминает зарегистрированным пользователям об отметке, принимает геопозицию только после действия пользователя и записывает приход или выход в Google Sheets. В журнал попадают время Астаны и UTC, Telegram ID, имя, username и распознанный адрес вместо координат.

## Требования

- Python 3.11 или новее.
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).
- Google-таблица и JSON-ключ сервисного аккаунта Google.

## Настройка Telegram

1. Создайте бота через `@BotFather` и скопируйте токен.
2. Откройте созданного бота и отправьте `/start`, чтобы зарегистрироваться для напоминаний.

## Настройка Google Sheets

1. В Google Cloud Console создайте проект и включите **Google Sheets API** и **Google Drive API**.
2. Создайте service account и скачайте JSON-ключ. Положите файл в корень проекта, например `service-account.json`.
3. Создайте Google-таблицу и поделитесь ею с адресом service account (поле `client_email` в JSON), предоставив права редактора.
4. Возьмите ID таблицы из адреса `https://docs.google.com/spreadsheets/d/<ID>/edit`.

Бот автоматически создаст листы `Attendance` и `Users` и добавит заголовки. Для определения адреса координаты передаются OpenStreetMap Nominatim; в новые строки таблицы записывается адрес (например, улица, Алматы, Казахстан), а не широта и долгота. Если сервис не сможет определить адрес, отметка не сохранится и бот попросит повторить отправку. Старые координатные столбцы будут сохранены для уже записанных данных.

Не отправляйте JSON-ключ и Telegram-токен в Git или другим пользователям. Геопозиция является персональными данными: ограничьте доступ к таблице только тем, кому он необходим.

## Установка и запуск (Windows PowerShell)

Сначала перейдите в корень проекта (папку, где находится `README.md`):

```powershell
Set-Location "C:\Users\notnik\OneDrive\Desktop\VSCODE КИРЮХА ГЕЙ"
```

Не выполняйте следующие команды из `C:\Windows\System32`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Заполните `.env`:

- `BOT_TOKEN` — токен от BotFather.
- `GOOGLE_SHEETS_ID` — ID таблицы.
- `GOOGLE_CREDENTIALS_FILE` — путь к JSON-ключу.
- `TIMEZONE` — часовой пояс IANA; для времени Астаны используйте `Asia/Almaty`.
- `REMINDER_TIMES` — одно или несколько локальных времен в формате `HH:MM`, через запятую.

Затем запустите бот через интерпретатор виртуального окружения:

```powershell
.\.venv\Scripts\python.exe -m attendance_bot.main
```

Бот и расписание работают, пока процесс запущен. Для регулярных отметок разместите его на постоянно работающем сервере. Каждая отметка требует, чтобы пользователь сам нажал кнопку отправки геопозиции в Telegram; бот не получает координаты в фоне.

## Меню бота

- **Отметиться** — записать приход с текущим временем и адресом.
- **Отметить выход** — записать время ухода и адрес.
- **Моя последняя отметка** — показать тип события, время Астаны и адрес последней записи.
- **Помощь** — краткая инструкция.

Время выводится в формате `13.10.2026 09:30:00 (Астана, UTC+05:00)`. После `/start` Telegram ID пользователя заносится в лист `Users`, и он получает напоминания в настроенное время.
